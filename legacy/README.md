# Legacy

Material kept in the repository for reference only. Nothing here is part of the
release: it is not in `GameData/` and is not attached to any part.

- `small-consoles/` — the capsule IVAs (Sirius, Neptune, Virgo) with the original,
  smaller console layout, as they were before the main panel was enlarged.
  The `INTERNAL` names carry a `tie_legacy_small_` prefix, so they never collide
  with the shipped IVAs.
